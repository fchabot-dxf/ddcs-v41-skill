# DDCS V4.1 — differences from Fanuc Macro B and the DDCS Expert M350

> Every measured statement names the bench test that measured it (see evidence.md).

**This controller is not Fanuc Macro B and not the DDCS Expert M350.** Each row is a habit an assistant would carry over from one
of them. The DDCS V4.1 and DDCS Expert M350 cells name the bench test behind them, or say they are not measured; the Fanuc
Macro B column is general Fanuc practice, not measured here.

| habit | DDCS V4.1 (this controller) | Fanuc Macro B | DDCS Expert M350 |
|---|---|---|---|
| Inline IF .. THEN | Stops the run mid-way (RESET) when the parser reaches it. Write a negated jump, the assignment, a label. *(AUDIT_V8_then, ALIAS_OLD_THEN (alias matrix))* | IF [cond] THEN #a = b is a normal statement. *(general Fanuc practice, not measured here)* | Rejected (IF <cond> GOTO <label> only). Write a negated jump, the assignment, a label. *(t2070)* |
| Jumps and loops (GOTO, WHILE) | Only in Macro Mode: parameter #122 = Enable, set by the operator. Without it a jump halts or freezes the controller. *(AUDIT_S5c_rerun (at #122=0 and #122=1))* | Always available; no mode to enable. *(general Fanuc practice, not measured here)* | Run in any mode; IF #a==b GOTO 1 with a space before the label is accepted. *(V11_gotospace.nc)* |
| Operator prompt (OK / Cancel) | A .rc dialog file opened with MarcoDialog "<full path>"; the operator HOLDS Ok, Cancel ends the program. *(AUDIT_R1 (held Ok))* | M00 or M01 with a comment; #3006 = n (message) stops with a message. *(general Fanuc practice, not measured here)* | #1505=1(message) is a blocking OK/Cancel dialog; there is no .rc dialog system (a firmware read, not a run). *(operator macros (READ_VAR.nc, COPY_WCS.nc))* |
| Operator number entry | An EDIT field in a .rc dialog, bound to the target variable (a digit wheel). *(AUDIT_R2, AUDIT_R2b, AUDIT_R21)* | No standard Macro B statement; builder-specific. *(general Fanuc practice, not measured here)* | #2070 = <var>(prompt) pauses for the operator to type a number. *(operator macros)* |
| What #1505 does | A silent variable write: no message, no pause. *(AUDIT_P2_1505)* | No standard meaning; #1000+ system variables are builder-specific. *(general Fanuc practice, not measured here)* | The dialog register: #1505=1(message) blocks for OK/Cancel. *(operator macros (READ_VAR.nc, COPY_WCS.nc))* |
| The #1500+ area | Machine and work position, the WCS table (#1512-#1551) and the tool table: never scratch. *(the variable table, #1500-#1551)* | Builder-specific system variables. *(general Fanuc practice, not measured here)* | System registers: the variable table names the inputs #1520-#1543 and the outputs from #1552 (the vendor's own macros use them; not bench-measured). *(the variable table, #1520-#1543)* |
| Work offsets G54..G59 | #1512-#1551, 6 per system (G52 last). *(the variable table, #1512-#1551)* | #5221-#5326 (20 per system). *(general Fanuc practice, not measured here)* | #805-#834, 5 per system; select with G54..G59 (writing #578 does not follow). *(panel read of all six systems)* |
| Tool length offsets | H1-H16 are #1561-#1576 (#1560 selects length or wear). *(the variable table, #1561-#1576)* | #2001+ or #11001+, by offset memory type. *(general Fanuc practice, not measured here)* | H01-H16 are #900-#915; the H word needs two digits (G43 H01). *(V6_set.nc, V6_restore.nc)* |
| Persistent variables a PC can read | #100-#499 persist and sit in the system share's uservar file; #100 is the dialog control variable. A PC reads it, never writes it: no run-time event reads the file back (only a reboot). *(uservar readback)* | #500-#999 keep their value through power-off; #100-#199 clear. *(general Fanuc practice, not measured here)* | #100-#499 sit in the work share's uservar file (its slots run on to #549, but #500 up may be the parameters Pr0-Pr49: not settled). A PC write during a run never reached the program; between runs it is not measured. *(operator test writes decoded over SMB)* |
| A variable from #2000 up | ⛔ Never: writing #3000 froze the controller (power-cycle needed). No #2042 beep, no #2070 entry here. *(AUDIT_MSG1)* | System variables (#3000 raises an alarm; #3006 stops with a message). *(general Fanuc practice, not measured here)* | System registers: #2070 = <var>(prompt) asks for a number, #2037 presses a key. *(operator macros)* |
| Modbus | There is no Modbus in the firmware; the PC channel is the network shares. *(firmware string scan 2025-04-04, serial send sweep)* | Not part of Macro B. *(general Fanuc practice, not measured here)* | A Modbus slave on serial port 2 (#279 set, then a reboot); G-code injection at register 3000. *(panel photo + live adapter test)* |
| Comments | A comment ends at its first ")": the rest of the line is read as code, which runs if it is valid and otherwise stops the run mid-way (a nested pair usually does; MOD_ZERO passed once); a ; comment after code also parses. *(AUDIT_R30 (first attempt), ALIAS_CMT_NESTED (alias matrix))* | ( text ); a nested parenthesis is not allowed. *(general Fanuc practice, not measured here)* | Comments cannot nest: the first ")" closes it and the rest is a syntax error. *(MGETDATA_TEST.nc)* |
| Dwell units | G04 P is milliseconds. *(inbound dwell test (P45000))* | G04 X in seconds; G04 P in milliseconds. *(general Fanuc practice, not measured here)* | G04 P is always milliseconds: G04 P3.0 is 3 ms, not 3 s. *(DWELL_units.nc)* |
| ATAN with two arguments | ATAN[y, x] (comma form), in degrees. *(S5o, S6g)* | ATAN[y]/[x]. *(general Fanuc practice, not measured here)* | ATAN[y, x] only; the slash form is a syntax error. *(V13_trig.nc, V13f_atan_comma.nc)* |
| A line the controller cannot parse | Stops the run mid-way (RESET), never at load: the parser reads ahead, so the stop comes up to 49 lines before the bad line; some variable writes before it had run, the moves near it had not. *(S6e, ALIAS_SPACE_MOVES, ALIAS_SPACE_MOVES_SYNC, ALIAS_SPACE_MOVES_FAR, ALIAS_NUM_COORD (alias matrix))* | An alarm at that block; the blocks before it have run. *(general Fanuc practice, not measured here)* | One bad line rejects the whole file. *(V13_trig.nc)* |
| The work position in a program | #790-#792 read 0 here; the work position is #1506-#1508. *(AUDIT_T3817_READ)* | #5041-#5043 hold the current work position. *(general Fanuc practice, not measured here)* | #790-#792 are the work X, Y and Z in the active work system. *(V14_wcs_pos.nc (popups photographed))* |
| ROUND | ⚠ ROUND truncates toward zero (ROUND[2.6] = 2): it does not round. *(AUDIT_HW1, AUDIT_MATH1)* | ROUND rounds to the nearest whole number. *(general Fanuc practice, not measured here)* | ROUND rounds; FIX truncates (FIX[2.9] = 2). *(Modbus injection test (#915 readback), a bench script re-run 20/20)* |
| Label indentation | Every line must start at column 0: a leading space is not refused at load; the run starts and stops mid-run ("Unrecognized file format", RESET), before the run reaches that line. *(AUDIT_LABEL_COL0, AUDIT_LABEL_SP1, AUDIT_LABEL_SP1_FAR)* | Leading spaces are ignored. *(general Fanuc practice, not measured here)* | An N label must start at column 0: a leading space is a syntax error. *(t2070 (controlled A/B))* |
